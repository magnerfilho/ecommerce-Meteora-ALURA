## Ecommerce-METEORA Alura - Bootstrap

Landing page da loja fictícia **Meteora**, feita no curso da Alura. É um front estático: vitrine de moda com carrossel, categorias, cards de produto e formulário de newsletter. Sem backend e sem checkout real.

O rodapé do site deixa explícito: projeto fictício, sem fins comerciais.

## O que tem na página

- Navbar (Home, Lojas, Novidades, Promoção) e busca
- Carrossel responsivo (mobile / tablet / desktop)
- Categorias (camiseta, bolsa, calçados, etc.)
- Produtos de exemplo: Calça Alfaiataria, Tênis Chunky, Jaqueta Jeans, Óculos Redondo, Bolsa coringa
- Faixa de facilidades (Pix, troca, sustentabilidade)
- Cadastro de e-mail para novidades

## Stack

- HTML
- CSS
- Bootstrap 5
- Bootstrap Icons
- `app.js` (anotações sobre Bootstrap; a página usa o bundle do CDN)

## Como abrir

Não precisa instalar dependências. Na pasta do projeto:

# opção 1 — abrir o arquivo
start index.html

# opção 2 — servidor estático, se tiver Python
python -m http.server 5500
